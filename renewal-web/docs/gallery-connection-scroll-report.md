# 갤러리 및 Connection 스크롤 수정

## 수정 범위
- index.html: Problem을 좌우 네 열과 중앙 메시지로 재구성. 각 이미지 열은 4장, 총 16장 + 중앙 Hero 재사용 이미지 1장.
- css/style.css: 갤러리 리듬, 외곽 열 이동, Connection 이미지 축소·넓은 열 간격, 고정 스테이지.
- js/script.js: 스크롤 진행도와 사진 전환·소개 퇴장·핵심 가치 고정을 동기화.

## 이미지 구성
기존 temp-* 및 직전 승인 후 제작한 why-* 이미지를 재사용했다. 새 스톡 이미지나 추가 생성 이미지는 없다. 양옆 대응 열의 크기와 세로 리듬은 같고, 세로형과 가로형 사진을 번갈아 배치한다. 데스크톱에서는 네 열이 모두 표시되고, 모바일에서는 외곽 두 열을 숨겨 가독성을 유지한다.

## 스크롤 흐름
Problem의 양 끝 열만 진행도에 따라 최대 240px 추가로 위로 이동한다. 중앙 콘텐츠와 안쪽 두 열에는 추가 이동을 적용하지 않는다.

Connection은 CSS sticky + requestAnimationFrame 기반의 네이티브 스크롤을 사용한다. 휠이나 터치 이벤트를 가로채지 않는다. CONNECT 제목 중앙이 사진 중앙 높이에 오면 목록의 상승을 멈추고, CONNECT 사진은 추가 스크롤에 따라 아래에서 위로 올라온다. BETTER TOGETHER는 계속 위로 퇴장한다. 사진·핵심 가치가 고정된 읽기 구간을 지나면 스테이지가 해제되어 Find Your Match로 이어진다. 역스크롤 시 소개 사진과 배치가 복원된다.

사진 폭은 데스크톱 콘텐츠의 5/12, 두 열 사이 간격은 1.5/12이다. 화면 높이와 열 너비에 따라 이미지 높이를 제한해 기존보다 작게 표시한다. 모바일은 이미지 위/본문 아래로 재배치한다.

## 검수
- 네 이미지 열 각각 4장 DOM 확인.
- 데스크톱: 끝 열 transform이 스크롤에 따라 -94.56px에서 -131.65px로 변화. 안쪽 열은 transform 없음.
- CONNECT 고정 시 사진 중앙과 제목 중앙의 차이 0.04px 미만.
- 사진 전환 진행도 0→1 및 역스크롤 intro 복원 확인.
- PLAY 클릭 시 설명과 선택 상태 정상 전환.
- 320×740px 및 390px 모바일: 가로 넘침 없음, 선택된 설명과 세 키워드가 스테이지 안에 표시됨.
- 768px 태블릿: 가로 넘침 없음. 사진/텍스트 사이 간격 유지.
- 모션 최소화 분기에서는 sticky 스토리 클래스를 제거하고 일반 문서 흐름으로 제공한다. 테스트 페이지의 분기 실행 확인.
- 고정 해제 후 Connection 하단과 Match 상단이 같은 좌표로 이어짐 확인.
- Hero, Match, Why OnCourt, Beyond, Final CTA의 HTML 내용 및 공통 GNB/Footer 유지.

레퍼런스 URL은 조회 도구에서 열리지 않아 사용자가 첨부한 세 화면을 시각 기준으로 사용했다. JavaScript 문법 및 압축 무결성 검사 후 제공한다.

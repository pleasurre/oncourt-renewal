- 문서: `copy-strategy.md` · v1.0 · 2026-10-25
- 제작 대상: **`index.html` 단일 랜딩페이지** (`#hero` → `#problem` → `#connection` → `#match` → `#why-oncourt` → `#beyond` → `#download` + Footer)
- 기준 문서: `prd(1).md`, `reference-analysis(2).md`, `ONCOURT_tokens_download(2).json`, `custom.md`(포함된 J.영 Design 기준)
- 우선순위: 사용자 최신 지시 > PRD의 페이지/섹션 잠금 > custom.md > 레퍼런스 분석 및 토큰. 이전 다중 페이지 기획은 **폐기**. 서브페이지·문의 폼·리스트·상세 카피는 제작 대상이 아님.
- 카피 상태: **기획 제안안**. 브랜드 공식 슬로건/공식 서비스 문구라고 주장하지 않음. 서비스 세부 사실과 법적 링크/수치는 공개 전 온코트 공식 자료로 확인.

## 1. 사이트 세계관 한 문장

> **같은 코트를 향한 마음이 만나는 곳 — 온코트는 혼자 시작한 테니스가 누군가와의 다음 랠리로 이어지도록 돕는다.**

### 세계관을 사용자 행동으로 번역하기
- **Alone:** 치고 싶은 마음은 있지만 함께할 상대가 없는 순간.
- **Connect:** 지역·일정·실력과 상대에 관한 정보를 확인하며 연결을 시작하는 순간.
- **Rally:** 새로운 파트너와 경기에 참여하고, 더 다양한 테니스 활동으로 이어지는 순간.
- **세계관 은유의 범위:** 랠리는 브랜드 서사와 장면 전환의 메타포다. 모든 정보성 문장을 테니스 은유로 쓰지 않는다.
- **브랜드 약속의 범위:** ‘언제나 상대가 있다’, ‘안전 보장’, ‘즉시 매칭 확정’ 등 검증할 수 없는 약속은 하지 않는다.

### 핵심 메시지 운용 원칙
1. Hero에서는 **브랜드 감성 + 서비스 정의 + 앱 다운로드**를 한 화면에 동시에 노출한다.
2. Problem은 사용자의 불편만 제시한다. 공포·불안 조장 또는 실증되지 않은 불편 통계를 쓰지 않는다.
3. Connection은 **Alone → Connect → Rally** 세 장면 모두에서 같은 인물/코트가 이어지는 시각적 서사를 카피로 보조한다.
4. Match는 앱 기능을 실제로 조작하는 듯한 허위 표현 없이 **이용 순서 설명**에 집중한다.
5. Trust는 수치보다 확인 가능한 기능을 먼저 이야기한다. 최신 공식 수치를 확보한 경우에만 통계 모듈을 활성화한다.
6. CTA는 랜딩에서 가짜 매칭을 실행하지 않고, 검증된 **앱스토어 다운로드 링크**로 안내한다.

## 3. 페이지 전체 톤앤매너

### Voice / Tone
- **명료함:** 감성적 브랜드 문장 바로 곁에 사용자가 할 수 있는 일을 설명한다.
- **활동적이되 과장하지 않음:** '다음 경기', '함께 치다', '찾다', '확인하다' 같은 행동 동사를 우선한다.
- **친근하지만 가볍지 않음:** '무조건', '꿀매칭', '역대급' 같은 광고/밈 문체를 피한다.
- **믿을 만한 표현:** 무료 매칭, NTRP, 매너 리뷰 같은 기능은 실제 제공·조건 확인 후 사용한다.
- **에디토리얼 리듬:** 영문 디스플레이는 짧게, 한글 제목은 의미 단위, 본문은 통상 1~2문장으로 제한한다.

### 한글 기준 — custom.md 내 jy-ux-lab.md 기준 반영
- 별도 `jy-ux-lab.md` 원본과의 동일성은 검증하지 못했으며, 첨부 custom.md에 포함된 **Base J.영 Design.md Reference**를 기준으로 삼는다.
- 영문 Hero/섹션 타이틀은 **Manrope 800**, 한국어 본문 **Pretendard 400**, 한글 소제목 및 CTA **Pretendard 600**을 우선한다(타이포 크기는 토큰에서만 가져온다).
- Hero 영문 `clamp(58px, 7vw, 112px)` / 섹션 타이틀 `clamp(32px, 5vw, 72px)` / 본문 `clamp(14px, 1.5vw, 16px)`은 **온코트 적용 토큰**이며 Waabi 실측값이 아니다.
- 영문 카피를 문장 구조까지 직역하지 않는다. 직관적인 한국어로 새로 쓴다.
- 대형 한글 제목은 1~2개의 의미 덩어리로 나눠 줄바꿈하고, 본문은 **최대 680px 읽기 너비** 안에서 자연스럽게 흐르게 한다.
- CTA는 2~8자 수준의 명확한 행동 문구를 우선한다. 버튼에 긴 감성형 문장을 쓰지 않는다.
- 제품 실제 화면, 대회 및 후기 관련 문구는 사실 여부 확인 전 과도하게 확정적으로 쓰지 않는다.

### Footer 문구
- 브랜드 설명: **함께 테니스할 파트너를 찾는 앱, 온코트.**
- 브랜드 마무리: **다음 랠리에서 만나요.**
- Footer 내 이동 링크: **처음으로** (`#hero`) · **온코트** (`#connection`) · **매칭** (`#match`) · **신뢰** (`#why-oncourt`) · **대회** (`#beyond`) · **앱 다운로드** (`#download`).
- 법적/운영 링크 라벨 후보: **개인정보처리방침**, **이용약관**, **문의하기**. **공식 URL 확인 후만 링크 출력**. 신규 HTML 페이지를 만들지 않음.
- 저작권: 공식 권리자 표기와 연도는 소스 확인 전 임의 삽입하지 않는다. 포트폴리오 하단에는 필요 시 **비공식 리디자인 콘셉트 프로젝트입니다.**를 명확히 표기(브랜드 공식 사이트로 오인 방지).

### 폼 라벨·빈 상태·오류 문구
- **폼:** 현재 PRD는 문의/가입/매칭 폼이 없으므로 폼 필드·제출/완료/검증 오류 카피는 **해당 없음 — 생성 금지**.
- **리스트 빈 상태:** 현재 자체 리스트/검색 기능 없음 → **해당 없음**.
- **다운로드 URL 미확인:** 화면에 가짜 다운로드 버튼을 만들지 않는다. 제작 점검 문구(비공개): `TODO: 공식 앱 다운로드 링크 검증 필요`.
- **공식 이미지 미확보:** 비공개 개발 알림: `TODO: 공식 원본 이미지 및 사용 권한 확인 필요`.
- **이미지 실패 시 대체 텍스트:** `테니스 코트에서 플레이하는 장면`, `온코트 매칭 화면`, `온코트 대회 운영 화면` 등 실제 내용에 맞춰서만 작성.
- **링크 오류 처리:** 기본 네이티브 링크 외 JS 에러 토스트 임의 추가 금지; 배포 전 URL QA로 차단.

## 8. 모바일에서 줄바꿈이 필요한 문장

> 아래 `<wbr>` 또는 문장 구분은 **구현 권고**이며 `tokens.json`에 없는 고정 폭을 임의로 추가하지 않는다. 줄바꿈은 모바일 실제 렌더에서 확인하고 의미 단위를 우선한다.

| 위치 | 데스크톱 표기 | 모바일 권장 구분 | 이유 |
|---|---|---|---|
| Hero 영문 H1 | `FIND YOUR RALLY.` | `FIND YOUR` / `RALLY.` | 큰 Manrope 800 디스플레이의 가로 넘침 예방 |
| Hero 한국어 | `당신의 랠리를 함께할 사람을 만나다.` | `당신의 랠리를` / `함께할 사람을 만나다.` | 수식과 핵심 메시지 분리 |
| Problem | `치고 싶은 날, 함께할 사람이 없다면?` | `치고 싶은 날,` / `함께할 사람이 없다면?` | 질문 호흡 유지 |
| Connection | `함께할 사람이 생기면, 테니스는 달라집니다.` | `함께할 사람이 생기면,` / `테니스는 달라집니다.` | 조건/결과의 의미 구분 |

## 9. 다음 정적 제작 단계 전달 사항

- **페이지:** `index.html` 외 HTML 금지. 섹션 ID 7개 고정, 하단 Footer 별도 유지.
- **카피 우선순위:** Hero에서 명확한 서비스 정의 → Problem/Connection에서 공감과 서사 → Match에서 절차 → Trust에서 검증 정보 → Beyond에서 확장 → Download에서 행동.
- **디자인:** 레퍼런스 Waabi의 선언형 Hero·이미지와 정보 영역의 대비만 추출; 브랜드 색·폰트는 custom/tokens 우선.

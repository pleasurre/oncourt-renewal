# 最新版 / 최신 수정 — 함께 움직이는 코트와 3D 테니스공

## 변경 사항
- 바닥 이미지를 고정 배경에서 이동하는 코트 좌표계 안으로 옮겼습니다. 공/라인/바닥이 같은 카메라 이동에 연동됩니다. 스크롤에 따라 다른 표면과 그림자 영역이 보입니다.
- 경로의 첫 좌표부터 출발합니다. 초기 진행도 0에서 경로 거리 0px, 공 중심은 시작점 41px(데스크톱 검수)입니다. 처음부터 화면 중간에 배치하지 않습니다.
- 우측 01~04 진행 레일과 하단 SCROLL TO ROLL 및 화살표를 HTML에서 삭제했습니다.
- 테니스공을 평면 SVG 회전에서 3D 구체 렌더링으로 교체했습니다. 구의 표면 법선, 고정 광원, 회전하는 펠트와 봉제선, 접지 그림자를 사용합니다.
- WebGL을 사용할 수 있으면 GPU shader로, 사용할 수 없으면 같은 구체 계산을 Canvas CPU renderer로 처리합니다. 클라우드 검수에서는 software-3d 대체 렌더러가 작동했습니다. 대체 렌더러 역시 평면 이미지 회전이 아니라 회전된 3D 구의 표면을 픽셀별로 계산합니다.
- 첨부된 정확한 선택 이미지(image-edit-target-f2837957737c25d4.png)를 편집 소스로 내장 이미지 생성 도구에 전달하여 공의 펠트 재질을 만들었습니다. 자산: img/match-ball-felt.webp. 프롬프트: docs/match-ball-material-prompt.txt.
- 공 재질은 파일을 직접 여는 환경의 Canvas 보안 제한을 피하도록 JS에도 data URL로 내장했습니다.
- 곡선의 연결부는 매끄러운 접선을 가진 연속 곡선으로 수정했습니다. 표시된 선과 이동 좌표는 같은 SVG path입니다.

## 확인 필요 사항
실제 iOS/Android 성능과 WebGL GPU 모드의 기기별 렌더링은 추가 검수가 필요합니다. 브라우저에서 WebGL이 비활성화된 경우 자동으로 CPU 3D 렌더링을 사용합니다. 모션 감소 설정의 네 단계 일반 문서 대체 구성은 유지합니다.

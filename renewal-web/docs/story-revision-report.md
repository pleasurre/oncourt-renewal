이번 요청이 기존 PRD의 Problem/Connection 구성보다 우선한다. 과거 `implementation-report.md`의 01–03 설명은 이전 구현 기록이며, 현재 구조는 본 문서를 기준으로 한다. tokens.json / custom.md / fonts.css 및 폰트 자산은 변경하지 않았다. 수치가 없는 갤러리 위치는 기존 4/8/12 컬럼, gutter, 간격, 이미지 비율을 조합한 검수용 구성으로 사용하며 새로운 확정 토큰으로 추가하지 않았다.

## 01 Hero — 몰입

- 기존 테니스 실사, 영문/한글 메시지, 다운로드 및 매칭 CTA 유지.
- 전체 너비 이미지와 최소 화면 높이(100svh에서 기존 헤더 높이 제외).
- 1200px 콘텐츠 정렬선 유지. Manrope 800 영문 / Pretendard 한글.
- 전체 사진을 균일하게 어둡게 하던 처리 대신 텍스트 방향에서만 짙어지는 대비용 오버레이 적용. 장식 그라디언트가 아니라 사진 위 텍스트를 읽기 위한 보조 처리.
- 추후 모션 연결점: `.hero-image--full[data-story-image="hero"]`.
- 상단 로고는 원본 흰색 알파 이미지를 그대로 사용하고 `.site-header .brand img { filter: brightness(0); }`로 검정색 표시. 밝은 헤더에서 대비 확보. 이미지 원본, 로고 형태, Footer는 유지.

## 02 The Problem — 공감

- 배경 #F5F3EA, 중심 이미지 1개 + 주변 사진 슬롯 6개.
- 중심 이미지는 Hero와 동일한 `img/oncourt-tennis.jpg`. 카드 라운드 16px, 원본 비율을 고려한 object-fit:cover 및 초점 조정.
- 중심 이미지가 위쪽 중앙에 작아진 상태로 놓이고, 중앙 공감 카피를 사이에 두고 주변 이미지들이 높이·크기를 달리하며 배치됨.
- 중앙 카피와 사진 슬롯은 서로 다른 그리드 트랙에 배치. absolute로 덮어놓지 않아 줄바꿈 시에도 분리됨.
- 카피: “치고 싶은 날, 함께할 사람이 없다면?” / “테니스를 즐기고 싶어도 일정과 실력이 맞는 파트너를 찾는 일은 생각보다 쉽지 않습니다.”
- 모션 연결점: `.problem-center-image[data-story-image="problem"]`.
- 스크롤 축소·패럴랙스·이미지 순차 등장은 구현하지 않음. 애니메이션 최종 배치만 정적으로 표현.

## 03 The Connection — 연결

- 기존 3단계 텍스트 스토리보드를 제거하고 이미지 1개 + 텍스트 1개로 단순화.
- Desktop: 12컬럼 기반 6:6, 이미지 왼쪽/텍스트 오른쪽, 세로 중앙 정렬.
- Tablet: 큰 이미지를 위쪽에 두고 텍스트를 한 컬럼 안쪽에서 시작하는 에디토리얼 흐름.
- Mobile: 이미지 위/텍스트 아래. 이미지는 4:5 슬롯, 16px 라운드.
- 요청한 THE CONNECTION / 한글 헤드라인 / 설명 / “매칭 알아보기 →” 적용.
- CTA는 기존 #match로 연결. 본문 max-width 680px 이하.

## 미확보 이미지

공식 홈페이지의 이미지 요소를 재확인했다. Hero에 쓰는 플레이 실사, 기존 앱·대회 화면, 로고는 확인되었으나 이번 요청의 주변 장면 6종 및 두 파트너 장면은 적합한 원본을 확보하지 못했다. 블로그 썸네일·마스코트·앱 화면을 테니스 현장 사진처럼 대체하지 않았다.

The Problem 주변 사진 6개 및 The Connection 이미지 1개는 현재 중립적 플레이스홀더다. 각 슬롯에 `이미지/사진 준비 중` 및 장면 설명을 표시했고 접근성 이름에도 미확보 상태를 명시했다. 승인 없이 스톡/AI 이미지를 삽입하거나 생성하지 않았다. 상세 목록과 프롬프트는 `story-image-plan.md` 참조.

- 상단 공식 로고 검정 표시 확인.
- Connection Desktop split 및 모바일 순서/그리드 경계 확인.

- #hero → #problem → #connection → #match → #why-oncourt → #beyond → #download ID/순서 유지.
- GNB, Footer, 04–07 HTML은 첨부 원본과 동일한지 문자열 비교. 기존 CSS 전체를 그대로 두고 범위가 제한된 규칙만 추가했으며 JS는 원본과 동일.
- 모든 내부 앵커 대상과 실제 이미지 경로 확인. GSAP/스크롤 핀/새 의존성 없음.

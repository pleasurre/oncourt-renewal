# 최신 수정: 문구 및 타이포 정리

- Hero 본문은 좌측 상단의 FIND YOUR RALLY만 남겼습니다. 기존 보조 문구, 본문 및 Hero 버튼을 제거했습니다. 공통 헤더의 로고·메뉴·다운로드는 유지합니다.
- CONNECT: 테니스를 좋아하는 사람들과 만나 새로운 인연을 시작합니다.
- PLAY: 나와 맞는 파트너와 더 자주 코트에 서며 함께하는 즐거움을 느낍니다.
- BELONG: 한 번의 경기를 넘어 함께하는 테니스 라이프 속에서 소속감을 느낍니다.
- 각 가치 설명은 소제목과 본문을 나누지 않은 한 문장입니다. Pretendard, 기존 body 크기 토큰(검수 시 16px), Regular 400, 회색 보조 글씨로 통일했습니다.
- Connection의 매칭 알아보기 링크를 삭제했습니다.
- 전 섹션의 번호/영문 소형 라벨을 삭제했습니다. 각 섹션의 주제목과 기능 안내 단계 번호는 유지합니다.
- 변경 파일: index.html, css/style.css, README.md, 이 보고서.
- JavaScript와 이미지 모션 제거 상태, 사진 선택 동작, 섹션 순서와 ID, 브랜드 토큰은 그대로 유지합니다.
- 검수: 390·430·768·1440px 가로 넘침 없음, 설명 3개 및 라벨 0개 확인. PLAY 선택 시 해당 문장과 이미지 표시 확인.

# ONCOURT 정적 수정 결과

이 문서가 최신 변경 기준입니다. 이전 보고서의 동일 크기 갤러리·이미지 이동 관련 내용은 이번 수정으로 대체됩니다.

## 수정 파일
- css/style.css
- js/script.js
- README.md, 이 보고서
- index.html은 기존 콘텐츠·이미지 경로·섹션 ID를 그대로 사용합니다.

## THE PROBLEM
- 좌우로 대응하는 사진은 같은 폭과 높이를 가집니다.
- 중심 사진은 큰 가로형, 상단 안쪽 쌍은 작은 가로형, 중앙 양옆 쌍은 세로형, 하단 쌍은 중간 가로형으로 구분합니다.
- 넓은 화면에서 바깥쪽 사진 쌍을 추가하고 서로 다른 정렬 높이로 리듬을 만듭니다.
- 16px 라운드 및 기존 3:2·4:5 비율 토큰을 재사용합니다.
- 모바일은 5장으로 정리하고 중앙 카피를 별도 행에 배치합니다.

## THE CONNECTION
- 소개 사진은 처음부터 완성 크기로 배치합니다.
- Problem에서 Connection으로 사진을 이동·확대하던 복제 이미지와 스크롤 보간 코드를 삭제했습니다.
- 아래에서 위로 등장하는 모션은 추가하지 않았습니다. 이미지 전환 시간은 0초입니다.
- CONNECT 제목이 읽기 기준선을 지나면 소개 사진을 선택된 가치 사진으로 즉시 교체합니다. 소개로 돌아오면 소개 사진으로 복귀합니다.
- 클릭 시 설명과 사진을 즉시 교체합니다. CONNECT는 1장, PLAY는 이전 CONNECT와 2장, BELONG은 이전 CONNECT·PLAY와 3장입니다. 미래 단계의 이미지는 숨깁니다.
- 상단 고정 메뉴와 기존 04–07, 다운로드 링크를 유지합니다.

## 검수
- 320, 390, 430, 768, 1024, 1440, 1740px 실제 브라우저 레이아웃 확인: 가로 넘침 없음, Problem 중앙 텍스트와 이미지 겹침 없음, 표시되는 좌우 쌍의 폭·높이 일치.
- CONNECT → PLAY → BELONG → CONNECT 클릭 검수: 표시되는 사진 수 1 → 2 → 3 → 1.
- Connection 이미지 transition-duration 0s 및 이동 복제 요소 없음 확인.
- JavaScript 구문 검사 통과. 모든 이미지 파일 경로 확인.
- 새 이미지를 생성하지 않았으며 기존 임시 이미지 8종을 유지합니다. 공식 이미지 확보 시 img/temp-*.webp를 교체하면 됩니다.

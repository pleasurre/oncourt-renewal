# Waabi 갤러리 측정 및 ONCOURT 적용

검수일: 2026-10-27 (한국 시간). 참조: https://waabi.ai/?ref=siteinspire 및 사용자 첨부 image(20261027-023316).png.

## 실제 브라우저 측정

Waabi를 직접 스크롤하고 표시된 요소의 DOM 좌표와 계산된 스타일을 읽었다. CSS 원본 전체나 모션 라이브러리를 복제하지 않고 화면 구성과 스크롤 위치에 따른 변화를 측정했다.

| 항목 | 레퍼런스 측정 | ONCOURT 적용 |
|---|---|---|
| 측정 화면 | viewport 1363×936px, 문서 콘텐츠 폭 1348px | 같은 화면에서 비교 |
| 사진 크기 | 125.875×125.875px | 125.875×125.875px |
| 크기 비율 | 133/1440 × viewport 너비 | 동일 비율, 작은 태블릿 최소64px·대형 화면 최대200px |
| 바깥 열 위치 | 왼쪽24px / 오른쪽24px | 동일 |
| 안쪽 열 위치 | 왼쪽16.667% / 오른쪽16.667% | 동일 |
| 인접 두 열 사이 빈 거리 | 약74.78px | 약74.78px |

| 모션 | 안쪽 열은 일반 스크롤. 끝 열은 추가 Y 이동. 관찰한 위치에서 -71.79px→-480px | 끝 열만 진행도에 따라 +120px→-480px 추가 이동 |

첨부 2048px 화면의 사진 폭은 약194px이다. 실제 브라우저에서 확인한 반응형 비율과 유사하다. 수치는 스크린샷 확대율과 스크롤 위치에 따라 달라질 수 있으므로 화면 비율을 기준으로 적용했다.

기존 고정120px 열 간격과 서로 다른 크기의 중앙 사진 구성을 대신해, 화면 비율에 맞춘 동일 크기 정사각형을 배치했다. 중앙 Hero 재사용 사진도 같은 크기의 정사각형이다. 레퍼런스의 넓은 여백을 유지하면서 기존 네 열·각4장 요구를 보존했다. 이미지 생성 없이 기존 자산을 재사용한다.

## 이미지가 이어지는 흐름

1. Hero → Problem: 첫 이미지가 스크롤에 따라 전체 화면에서 중앙 정사각형 카드의 위치·크기로 축소 이동한다. 기존 헤드라인은 원래 좌측 하단에서 사라진다.
2. Problem 두 번째 열: 마지막 네 번째 사진은 temp-aerial.webp이며, BETTER TOGETHER의 소개 사진과 동일한 파일이다. 이전 중앙 텍스트 아래의 중복 사진은 제거했다.
3. Problem → Connection: 섹션이 viewport 높이의85% 지점에 진입할 때 마지막 카드를 출발점으로 삼는다. 사진이 확대·이동하며 Connection 사진 영역에 도착한다. 시작·도착 요소의 실제 좌표를 매 프레임 읽어 창 크기 변화에도 경로를 맞춘다.
4. 전환 중 원본과 도착 사진을 숨기고 aria-hidden 장식 레이어 하나로 이동을 보여준다. 같은 사진이 두 곳에 중복 노출되지 않는다. 완료 후 의미 있는 원래 img 요소가 다시 표시된다.
5. Connection 진입: BETTER TOGETHER 제목 자체가 사진 중앙 높이에 맞는다. 설명은 제목 아래에 표시한다.
6. CONNECT 도달: 이전 소개 사진은 중앙으로 축소·퇴장, CONNECT 사진은 아래에서 상승한다. 최종 고정점은 CONNECT 보조글의 중앙이다.

GSAP이나 추가 의존성 없이 native scroll + CSS sticky + requestAnimationFrame으로 구현했다. 스크롤 위치가 기준이므로 역방향으로도 복원된다. 휠·터치를 가로채지 않는다. prefers-reduced-motion 환경에서는 공유 이미지 이동과 시차 효과를 제거한다.

# 정사각형 이미지 및 CONNECT 보조글 정렬

- Problem의 네 열 16장과 텍스트 아래 추가 사진을 1:1로 변경. 중앙 Hero 재사용 사진은 기존 3:2 유지.
- Connection 사진은 데스크톱·모바일 모두 1:1. 화면 높이와 열 너비를 고려해 한 변의 길이를 결정.
- BETTER TOGETHER와 CONNECT 사이 간격은 데스크톱 +140px, 모바일 +80px 확장.
- CONNECT 제목이 사진 중앙을 지날 때 기존 사진 중앙 축소·퇴장 및 새 사진 상승 시작.
- 최종 고정 위치는 PLAY에서 CONNECT 보조글의 중앙으로 변경. 소개 문구는 계속 위로 퇴장.
- 흰색 배경, 갤러리 180px 세로 간격·데스크톱 120px 가로 간격, 다른 섹션 유지.

검수: 데스크톱 Connection 500×500px, CONNECT 보조글 중앙과 사진 중앙 오차 약 0.12px. 갤러리 카드 17장의 가로·세로 동일 확인. 중앙 Hero 3:2 유지 확인. 390×840px 모바일 사진 258.39×258.39px, 가로 넘침 및 본문 잘림 없음. JavaScript 문법 및 ZIP 무결성 검사 완료.

수정 파일: css/style.css, js/script.js. 이미지 원본을 훼손하지 않고 object-fit:cover로 화면 비율을 조정했다.

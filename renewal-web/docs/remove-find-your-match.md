# Find Your Match 삭제

중복되는 기능 설명을 줄이기 위해 Find Your Match 섹션을 삭제했다. Connection → PLAY WITH CONFIDENCE → Beyond the Match → Final CTA로 이어진다. 공통 GNB·Footer의 매칭 메뉴를 제거하고 기존 신뢰 메뉴는 유지했다. 긴 스크롤 구간, 3D 공 렌더링, 코트 경로 계산과 해당 전용 스타일도 제거했다. 브랜드 스토리 이미지 이동과 Why 탭은 유지한다.

검수: 섹션 6개, #match 참조 없음, 내부 앵커 모두 존재, JS 문법 검사 통과.

추가: Problem 보조글을 세 문장으로 확장하고 데스크톱에서 문장별 한 줄로 표시한다. 모바일에서는 자연스러운 자동 줄바꿈을 허용한다.

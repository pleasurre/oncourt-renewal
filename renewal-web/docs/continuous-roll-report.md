# 최신 수정 — 연속 롤링과 코트 표면

- 체크포인트 정지/감속 구간을 제거했습니다. 스크롤 진행도와 이동 경로의 누적 거리를 선형으로 연결합니다. 스크롤 중단 시에는 현재 위치를 유지하고, 스크롤을 이어가면 정지점 없이 계속 굴러갑니다.
- 텍스트 전환과 공 이동을 분리했습니다. 01·02 왼쪽, 03·04 오른쪽 배치는 유지합니다. 02 설명은 공이 왼쪽 텍스트 영역을 침범하기 전에 먼저 사라집니다.
- 마지막 카메라 이동은 연속적으로 감속하고 공은 같은 경로를 따라 계속 내려갑니다. 퇴장 시 공 투명도·크기는 바꾸지 않습니다.
- 얇은 1.5px 선을 모바일 12px~데스크톱 30px의 넓은 아이보리 페인트 띠로 변경했습니다. SVG 페인트 질감을 더했습니다. 표시 경로와 실제 공 이동 경로는 같은 path입니다.
- 생성한 녹색 아크릴 하드코트 표면과 자연광/대각선 그림자를 배경에 적용했습니다. 첨부 시안의 재질을 참고했으며 시안 자체를 배경으로 늘려 쓰지 않았습니다.
- 좌측 상단 제목은 FIND YOUR MATCH로 수정했습니다. 04 /는 삭제했습니다.
- 우측의 01~04 작은 진행 표시를 추가하고 현재 설명과 동기화했습니다. 모바일에서는 숨깁니다.
- Hero, Problem, Connection 및 05~07, GNB/Footer의 HTML은 직전 수정본과 같습니다.

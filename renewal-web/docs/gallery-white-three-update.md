# The Problem 수정

- 앞선 코트 장면과 갤러리를 독립된 레이어로 분리해 코트가 흰색 배경 위에 겹쳐 보이지 않게 수정했습니다.
- 갤러리 배경을 불투명한 흰색으로 고정하고 움직이는 외곽 사진이 섹션 밖으로 넘치지 않도록 했습니다.
- 네 열의 사진을 각각 4장에서 3장으로 줄였습니다. 모바일은 기존대로 안쪽 두 열이 보입니다.
- Connection으로 이어지는 마지막 항공 사진과 기존 공유 이미지 전환은 유지했습니다.
- 사진 간격과 정사각형 비율을 유지하고 갤러리 전체 높이는 3장에 맞춰 줄였습니다.
- 수정 파일: index.html, css/style.css.

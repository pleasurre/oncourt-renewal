# GNB / Hero 수정

- 첨부 ZIP의 Hero는 영상이 아닌 img/hero-tennis-friends.png (2048×1143)입니다. 원본 파일과 HTML은 변경하지 않았습니다.
- GNB: sticky 유지, #FFFFFF, 그림자·구분선 없음. 문서 흐름에서 독립된 공간을 차지합니다.
- Hero: GNB 바로 아래 시작. 프레임 높이는 데스크톱에서 min(화면 높이 − 실제 GNB 높이, 화면 너비 × 1143 / 2048)입니다. 과도하게 긴 화면에서도 원본보다 확대하지 않습니다.
- 768px 미만: 프레임 높이는 min(사용 가능한 화면 높이, 화면 너비 × 3 / 4). 두 인물을 함께 보여주기 위해 세로 풀스크린 대신 4:3을 사용합니다.
- object-fit: cover, object-position: center top. 상단 크롭을 방지하며 하단을 단순 이동시키지 않습니다. 매우 넓고 낮은 창에서는 하단 크롭이 남을 수 있습니다.
- 기존 25svh 스크롤 고정 구간을 유지하고 진행률 계산을 실제 프레임 높이에 맞췄습니다. 모션 감소 환경에서는 고정 구간이 없습니다.
- 헤더 크기 변경은 ResizeObserver로 반영합니다.
- 기존 흰색 제목과 타이포그래피를 유지하고, 하단 42% 영역에만 대비 그라데이션을 적용했습니다.

## 검수 및 한계
원본 ZIP과 비교해 CSS 및 Hero 전용 JS만 수정했음을 확인했습니다. 이후 HTML과 기능 스크립트, 모든 이미지 파일은 동일합니다.
브라우저 실행 파일이 없고 다운로드가 손상된 응답으로 실패해 실제 데스크톱·태블릿·모바일 렌더링 검수는 완료하지 못했습니다.
원본 사진은 머리 위 여백 자체가 적습니다. CSS는 원래 존재하는 여백을 보존할 수 있으나 추가 여백을 만들 수 없습니다. 더 넓은 여백이 필요하면 다음 영상 제작 시 상단 여백이 있는 와이드 구도가 필요합니다.
